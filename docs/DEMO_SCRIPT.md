# 45-Second Demo Script

Use this script if you want to record a true Excel screen capture in addition to the included GIF.

## 0-5s - Start Here

Open `README` and briefly show the workbook guide.

Narration/caption: **"Multi-source TfL analytics model built entirely in Excel using Power Query, Power Pivot and DAX."**

## 5-15s - Executive Dashboard

Open `Executive Dashboard`.

- Change Calendar Year from 2026 to 2025 and back.
- Change Financial Year once.

Caption: **"Independent calendar-year and TfL financial-year filters keep demand and service-performance contexts separate."**

## 15-25s - Station Explorer

Open `Station Explorer`.

- Search/select a major station such as Waterloo or Victoria.
- Change Day Type from Weekday to Weekend.

Caption: **"Station-level KPIs, ranking, directionality and weekday/weekend behaviour update through slicers."**

## 25-35s - Peak Flow Analysis

Open `Peak Flow Analysis`.

- Select `AM Peak` in Time Band.
- Choose a NUMBAT line.

Caption: **"NUMBAT is reshaped from 96 quarter-hour fields into a reusable 15-minute analytical model."**

## 35-45s - Refresh / auditability

Briefly show `Data Quality`, `Methodology` and `Source Register`.

Then use `Data > Refresh All` only if the local source paths are configured.

Caption: **"Refresh flows from TfL source files through Power Query, the Data Model and DAX into the dashboards; QA checks and source freshness remain visible."**

## Recording tips

- Record at 1080p.
- Keep Excel zoom around 85-100%.
- Hide formula bar/ribbon only if it improves the dashboard view.
- Use a slow cursor and one deliberate slicer change at a time.
- Export as MP4 or convert to a 30-60 second GIF for GitHub.
